# 첨부 지도 이미지 참고 설명

첨부된 네이버 지도 이미지는 대전 중앙시장권역의 보행 네트워크를 구축하기 위한 참고 자료이다. 이미지에서 보라색 또는 파란색으로 보이는 선은 사람이 걸을 수 있는 인도, 골목, 시장 내부 통로 후보로 해석할 수 있다.

다만 이 이미지는 GIS 좌표가 포함된 원자료가 아니라 화면 캡처 이미지이다. 따라서 이미지 픽셀 좌표를 실제 위도·경도처럼 사용할 수 없고, 이미지에서 보이는 선을 자동으로 추출하더라도 공식 보행 네트워크로 간주할 수 없다.

이 프로젝트에서는 이미지를 다음 용도로만 사용한다.

- 중앙시장, 중앙종합시장, 생선골목, 한복거리, 신중앙시장 주변의 보행축을 확인하는 참고 자료
- 대전천 쪽 서측 접근로와 대전로 쪽 동측 접근로를 파악하는 참고 자료
- Leaflet 편집 모드에서 노드와 엣지를 수동으로 그릴 때 참고하는 배경 정보

최종 경로 계산에는 사용자가 Leaflet 지도 위에서 검토·보정한 `network_nodes.geojson`과 `network_edges.geojson`만 사용해야 한다.
