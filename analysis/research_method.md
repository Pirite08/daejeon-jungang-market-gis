# 연구 방법

## 1. 점포 데이터 품질 진단

`stores.geojson`와 `metadata.json`을 읽어 전체 점포 수, 중앙시장명 직접 매칭 점포 수, 주변 권역 점포 수, 업종별 점포 수, 좌표 중복 정도, 도로명주소 중복 정도를 분석한다. 이 과정은 현재 데이터가 실제 점포 출입구 좌표가 아니라 주소 또는 건물 대표점 좌표일 가능성을 확인하기 위한 절차이다.

## 2. 장보기 품목군 재분류

기존 상권업종 대분류, 중분류, 소분류는 연구자가 장보기 목록을 구성하기에는 너무 행정적이다. 따라서 상호명, 업종명, 소분류명을 기준으로 `과일·채소`, `정육`, `수산·건어물`, `반찬·식료품`, `떡·한과`, `분식·먹거리`, `카페·음료`, `생활용품`, `보건·약국` 등 연구용 장보기 품목군을 부여한다.

## 3. 업종별 공간 분포 분석

점포를 지도에 표시하고 업종 대분류와 장보기 품목군별 분포를 비교한다. 이를 통해 중앙시장권역에서 어떤 업종이 중심부에 집중되고 어떤 업종이 외곽부까지 분산되는지 살핀다.

## 4. 중심부·중간부·외곽부 구역 분석

중앙시장 직접 매칭 점포의 평균 좌표를 중심점으로 설정하고, 0~100m를 중심부, 100~200m를 중간부, 200~300m를 외곽부로 구분한다. 각 구간의 점포 수와 업종 구성을 비교해 시장 내부와 주변 상권의 공간적 차이를 분석한다.

## 5. 구매목록 기반 후보 점포 추천

사용자가 여러 장보기 품목군을 선택하면 각 품목군에 해당하는 후보 점포를 3~5개 추천한다. 후보 선정에는 품목군 일치 여부, 중심점과의 거리, 시장명 직접 매칭 여부, 좌표 중복 정도, 외곽부 포함 옵션을 반영한다.

## 6. 경로 유형별 비교

현재 단계에서는 실제 보행 네트워크가 없으므로 점포 좌표 간 직선거리를 이용해 예비 경로를 비교한다.

- 빠른 장보기: 총 이동거리 최소화를 우선한다.
- 초행자 친화형: 중심부 점포와 시장명 직접 매칭 점포를 우선한다.
- 상생형: 외곽부 또는 덜 노출될 수 있는 점포를 일부 포함한다.

## 7. 향후 보행 네트워크 기반 확장

추후 `network_nodes.geojson`와 `network_edges.geojson`에 실제 출입구, 교차점, 골목, 주요 통로, 통로 폭, 혼잡도, 방향 전환 난이도, 인지 비용을 입력하면 Dijkstra 또는 A* 기반의 네트워크 경로 계산으로 확장할 수 있다.
