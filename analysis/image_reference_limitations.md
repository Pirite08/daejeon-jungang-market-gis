# 이미지 참고자료의 한계

첨부된 네이버 지도 이미지는 GIS 데이터가 아니라 화면 캡처 이미지이다. 이미지에는 실제 위도·경도 좌표, 보행로의 정확한 선형, 통로 폭, 현장 통행 가능 여부가 포함되어 있지 않다.

따라서 다음 원칙을 지켜야 한다.

- 이미지 픽셀 좌표를 실제 좌표처럼 사용하지 않는다.
- 이미지에서 보이는 보라색/파란색 선을 공식 보행 네트워크라고 표현하지 않는다.
- 자동 추출을 하더라도 참고 레이어 또는 초안으로만 사용한다.
- 최종 데이터는 사용자가 Leaflet 편집 모드 또는 QGIS에서 검토·보정한 GeoJSON이어야 한다.
- 실제 경로 계산에는 `network_nodes.geojson`과 `network_edges.geojson`만 사용한다.

이 이미지는 보행 네트워크를 어디에 그릴지 판단하는 참고 자료이며, 최종 분석 결과의 근거 데이터는 아니다.
