# 최종 연구보고서 목차

## 1. 연구 동기

전통시장은 대형마트와 달리 상품군 배치와 내부 동선이 직관적으로 정리되어 있지 않아 초행자가 목적 점포를 찾기 어렵다. 대전 중앙시장권역을 사례로 이러한 이용 불편을 GIS 데이터로 분석한다.

## 2. 연구 필요성

길찾기 어려움은 개인의 불편을 넘어 시장 접근성, 점포 노출, 소외 골목 활성화 문제와 연결된다. 따라서 소비자 편의성과 상권 균형을 함께 고려한 분석이 필요하다.

## 3. 데이터 수집 및 전처리

소상공인시장진흥공단 상가정보에서 대전광역시 동구 중앙동 점포를 추출하고, 중앙시장 관련 명칭이 포함된 점포를 기준으로 중심점을 설정한다. 중심점 반경 300m 안의 점포를 분석 대상으로 삼는다.

## 4. 대전 중앙시장권역 점포 분포 분석

전체 점포 수, 직접 매칭 점포 수, 주변 권역 점포 수, 업종 대분류·중분류·소분류 분포를 분석한다.

## 5. 장보기 품목군 재분류

상호명과 업종명을 바탕으로 과일·채소, 정육, 수산·건어물, 반찬·식료품, 떡·한과, 분식·먹거리 등 장보기 연구용 품목군을 부여한다.

## 6. 중심부·외곽부 공간 구조 분석

0~100m 중심부, 100~200m 중간부, 200~300m 외곽부로 나누어 점포 분포와 품목군 차이를 비교한다.

## 7. 구매목록 기반 장보기 동선 추천 모델

사용자가 선택한 여러 품목군에 대해 후보 점포를 추천하고, 여러 점포를 어떤 순서로 방문할지 예비 경로를 구성한다.

## 8. 경로 유형별 비교

빠른 장보기, 초행자 친화형, 상생형 경로를 비교한다. 각 경로의 총 거리, 예상 이동시간, 중심부 점포 수, 외곽부 점포 수, 직접 매칭 점포 수, 빠른 장보기 대비 거리 증가율을 분석한다.

## 9. 결과 해석

빠른 장보기 경로는 이동거리 측면에서 효율적이고, 초행자 친화형 경로는 중심부와 직접 매칭 점포를 더 많이 포함한다. 상생형 경로는 일정 거리 증가를 감수하면서 외곽부 점포 노출을 늘리는 가능성을 보여준다.

## 10. 데이터 한계와 후속 연구

현재 점포 좌표는 주소 기반 대표점일 가능성이 높고, 실제 보행 네트워크가 없다. 따라서 현재 경로는 실제 보행 길찾기가 아니라 직선거리 기반 예비 분석이다. 후속 연구에서는 QGIS 또는 현장조사를 통해 보행 네트워크를 구축해야 한다.

## 11. 전통시장 이용 편의성 개선 제안

장보기 품목군별 안내, 초행자 친화형 추천 경로, 소외 골목을 자연스럽게 노출하는 상생형 경로, 출입구 중심 안내체계, 점포군별 기준점 안내를 제안한다.
